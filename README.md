# Screen Partner

Screen Partner is a lightweight cross-platform desktop pet that reacts to system activity while keeping every sprite action visually complete.

The first milestone targets Windows 10/11 x64 and macOS Apple Silicon with Tauri 2, Rust, and a Vanilla JavaScript renderer. Codex v1 `pet.json + spritesheet.webp` resources are the initial compatibility target.

Development is currently in the bootstrap stage. The detailed product and architecture baseline lives under `docs/`.
